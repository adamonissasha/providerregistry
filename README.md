# Сервис-реестр HTTP-клиентов поставщиков

## Описание задачи
Сервис представляет собой реестр поставщиков, который позволяет проверять доступность номера телефона через внешние API.
Поставщика можно идентифицировать по `id`, у него есть базовый `baseUrl` и `apiKey`. Набор поставщиков можно полностью заменить в рантайме.

## Стек технологий
- **Java 17**
- **Spring Boot 3.3.5** (Spring Framework)
- **JUnit 5** + **Mockito** (тестирование)
- **Gradle** (сборка)
- **Jackson** (парсинг JSON)

## Архитектура проекта
Проект разделен на слои, чтобы обеспечить слабую связанность и удобство тестирования:

- `domain` — неизменяемые модели (`Provider`, `PhoneAvailability`) и бизнес-исключения. Не зависит от Spring и HTTP.
- `registry` — потокобезопасный реестр поставщиков (`ProviderRegistry`), поддерживающий полную замену списка. В подпакете `json` находится `ProviderJsonReader` для чтения списка из файла.
- `client` — интеграция с поставщиками. В подпакете `transport` выделен интерфейс `HttpTransport` и его реализация `JdkHttpTransport`. Это позволяет подменять реальный сетевой вызов в тестах.
- `service` — бизнес-логика (`PhoneAvailabilityService`), которая оркестрирует работу реестра и клиентов.
- `config` — конфигурация Spring и инициализация приложения (`ProviderRegistryInitializer`).

## Особенности реализации
1. **Без веб-контроллера.** По условию задачи создание REST-эндпоинта не требовалось. Логика сервиса изолирована и покрыта Unit-тестами. В `application.yml` отключен запуск веб-сервера (`web-application-type: none`), чтобы приложение не висело в фоне.
2. **Безопасность в тестах.** В тестах реальный сетевой вызов полностью подменяется через Mockito (`HttpTransport` и `ProviderClientFactory`). Ни один реальный HTTP-запрос во время тестирования не выполняется.
3. **Потокобезопасность реестра.** В `ProviderRegistry` используется `volatile Map`, а метод `replaceAll` атомарно заменяет текущий набор поставщиков.
4. **Обработка ошибок.**
    - `200` + `{"status":"ok"}` -> `PhoneAvailability.AVAILABLE`
    - `404` -> `PhoneAvailability.UNAVAILABLE`
    - Все остальные коды и сетевые ошибки пробрасываются вызывающему коду в виде `PhoneCheckException`.
